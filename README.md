
# 📊 HR Analytics Dashboard

## 📌 Project Overview

The **HR Analytics Dashboard** is a data analytics project designed to analyze employee-related data and provide meaningful insights into workforce trends.

The dashboard helps HR teams understand important factors such as **employee attrition, salary distribution, department-wise employees, job roles, age groups, and overall workforce patterns** through interactive visualizations.

## 🎯 Objectives

* Analyze employee data and workforce trends.
* Understand employee attrition patterns.
* Analyze salary and job-role distribution.
* Compare employees across different departments.
* Create interactive and easy-to-understand visualizations.
* Support data-driven HR decision-making.

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard creation and data visualization
* **Microsoft Excel** – Data cleaning and preprocessing
* **Data Analytics** – Exploring and interpreting employee data

## 📊 Key Dashboard Insights

The dashboard provides analysis of:

* 👥 Total Employees
* 📈 Employee Attrition
* 💰 Salary Distribution
* 🏢 Department-wise Employee Analysis
* 💼 Job Role Analysis
* 🎂 Age Group Analysis
* ⚧ Gender Distribution
* 📊 Employee Performance and Workforce Trends

## 🔄 Project Workflow

**Raw Data → Data Cleaning → Data Transformation → Data Analysis → Visualization → HR Insights**
